# Bransons custom Circle Card sample

`Bransons-Circle-Card.html` is a self-contained, unofficial ScaleSmiths demonstration matching the supplied green and cream concept. It includes embedded images from the official Bransons website, a demo spin, call and directions links, official department links, vCard download and Web Share/clipboard support. The spin explicitly saves no relationship. No business account is created or published.

Business details and photographs were checked against https://www.bransons-hga.co.uk/ on 9 November 2026. The B monogram is a concept identity, not an asserted official logo.

Deployment and attachment are pending. The active application's sample route and account data are absent from the repository default branch. `inspect-samples.py` reads the live service configuration, sample renderer references and existing sample entries on Trevor Newton-Bradley's cards. It changes no files, services or database rows and prints no runtime environment values.

The supplied live-source snapshot identifies the native `CircleCardPrepared` shelf and its founder authorization contract. `install-sample.py` validates its payload using the live parser, checks the founder's active operator access and existing Strelley Hall record, serves the checksum-pinned static design through three exact Nginx aliases, verifies those responses, and creates a private, unclaimed Bransons prepared draft. Its first preview link opens the custom design. This adds the card to the existing shelf without rebuilding the app; it does not add a new Custom tab to the shared preview renderer. The clearly labelled static sample is public like the existing `/samples/*.html` concepts. No invitation or billing change occurs.

Reruns preserve the installed draft and refuse to overwrite other Bransons records. Changed routing, release identity, authorization or payload validation stop installation. Nginx is backed up and restored on routing or pre-attachment failure. No existing prepared card is updated. Run this in the existing authorised root server session. Do not replace the live app with this repository's older default branch.

Validation: HTML structure and embedded image decoding checked; JavaScript and Python syntax checked. Four installer tests verify route preservation, rerun idempotency, conflict rejection and exact byte-response health checks.
