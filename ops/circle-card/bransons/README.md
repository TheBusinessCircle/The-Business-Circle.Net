# Bransons custom Circle Card sample

It includes embedded images from the official Bransons website, a demo spin, call and directions links, official department links, vCard download and Web Share/clipboard support. The spin explicitly saves no relationship. No business account is created or published.

Business details and photographs were checked against https://www.bransons-hga.co.uk/ on 9 November 2026. The B monogram is a concept identity, not an asserted official logo.

The clearly labelled static sample is public like the existing `/samples/*.html` concepts. No invitation or billing change occurs.

Reruns preserve the installed draft and refuse to overwrite other Bransons records. Changed routing, release identity, authorization or payload validation stop installation. Do not replace the live app with this repository's older default branch.

Failure reporting identifies the stage and redacts secret environment values and URLs.
